## Deploy to GitHub Pages (`username.github.io`)

### Option 1: As your main personal website (`username.github.io`)
1. Create a repository on GitHub named: **`<your-username>.github.io`**
2. In this folder (`C:\Users\spenc\projects\portfolio-case-studies`), run:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-username>.github.io.git
   git branch -M main
   git push -u origin main
   ```
3. Your site will automatically go live at: **`https://<your-username>.github.io`**

### Option 2: As a project repository (`username.github.io/portfolio`)
1. Create a repository on GitHub named: **`portfolio`** (or any name)
2. Push this repo:
   ```bash
   git remote add origin https://github.com/<your-username>/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. In GitHub repo settings: **Settings → Pages → Build and deployment → Source**, select **GitHub Actions** (or deploy from branch `main` / `root`).
4. Your site will go live at: **`https://<your-username>.github.io/portfolio`**
